⚡ Real-time Stack

Frontend: Geolocation.watchPosition() → Socket.io emit
Backend: Socket rooms per couple, broadcast deltas
Map: Leaflet (lightweight, custom styling)
DB: MongoDB Location model w/ 2dsphere index
Animations: Reuse Framer Motion from MoodTracker

🔒 Key Privacy Rules

✓ Explicit dual consent

Both partners must independently toggle "Share my location" ON. One-sided sharing is never visible.

✓ Transparent pause

When one pauses, BOTH screens show "⏸️ Sharing paused" immediately. No hidden sharing.

✓ Auto-delete history

Trail data + location history auto-purge after 48 hours (user-configurable: 24/48/7 days).

✓ No geo-spam

Notifications throttled: "on my way" only once per session. Arrival celebrate only once per meeting. Prevent notification fatigue.

⚠️ Edge Cases to Handle

Scenario Behavior
Location permission denied Show prompt: "Re-enable in Settings" + fallback to manual location input
No internet connection Store location locally, sync when connection restored
Signal lost in tunnel Show last known position + "Last seen 5 mins ago" (don't assume they moved)
Low battery (<10%) Auto-pause location sharing + notify partner "Battery too low, paused"
Account deletion All location history auto-deleted. Partner sees "Account deleted" message.
